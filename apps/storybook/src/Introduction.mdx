<DocSection n={2} title="Install" meta="npm" description="Tokens alone work with any framework. The components need React 19.">

```bash
npm install @med-o/design-tokens            # tokens only
npm install @med-o/design-tokens @med-o/ui   # tokens + React components
```

```tsx
import '@med-o/design-tokens/css';
import '@med-o/ui/styles.css';
import { Button } from '@med-o/ui';
```

</DocSection>

<DocSection n={3} title="Use the tokens" meta="CSS · Tailwind" description="Import the variables once. Then use only semantic tokens.">

```css
/* main.css */
@import "@med-o/design-tokens/css";               /* variables, light + dark */
@import "@med-o/design-tokens/css/typography.css"; /* optional: .medo-text-* classes */

.card {
  background: var(--medo-color-surface-raised);
  color: var(--medo-color-text-primary);
  padding: var(--medo-space-6);
  border-radius: var(--medo-radius-lg);
  box-shadow: var(--medo-shadow-elevation-2);
}
```

</DocSection>

<DocSection n={4} title="Light and Dark" meta="System · forced" description="The tokens follow the operating system. Force a theme for the whole page or for one area.">

```html

```
