<DocSection n={2} title="Use the tokens" meta="CSS · Tailwind" description="Import the variables once. Then use only semantic tokens.">

```css
/* main.css */
@import "@medo/design-tokens/css";               /* variables, light + dark */
@import "@medo/design-tokens/css/typography.css"; /* optional: .medo-text-* classes */

.card {
  background: var(--medo-color-surface-raised);
  color: var(--medo-color-text-primary);
  padding: var(--medo-space-6);
  border-radius: var(--medo-radius-lg);
  box-shadow: var(--medo-shadow-elevation-2);
}
```

</DocSection>

<DocSection n={3} title="Light and Dark" meta="System · forced" description="The tokens follow the operating system. Force a theme for the whole page or for one area.">

<DocSection n={5} title="Updating from Figma" meta="Tokens" description="Generated files are never edited by hand.">

1. Change variables or styles in Figma.
2. Export them to `figma/variables.json` (see README).
3. Run `npm run tokens:from-figma`, then `npm run build:tokens`.
