<DocSection n={2} title="Usage" description="Three ways, same result.">

```html
<p class="medo-text-body-md">…</p>   <!-- plain CSS class -->
<p class="text-body-md">…</p>        <!-- Tailwind -->
```

<Notes>
  <p>CSS shorthand: <Tok>font: var(--medo-typography-body-md)</Tok>. The shorthand has no letter spacing – prefer the class.</p>
  <p>Small styles – 11 px (<Tok>label/xs</Tok>) and 12 px (<Tok>label/sm</Tok>, <Tok>caption</Tok>, <Tok>overline</Tok>, <Tok>code/sm</Tok>) – are for short metadata only: counters, timestamps, badges, table meta. Never for running text, descriptions or anything people must read to act; use <Tok>body/sm</Tok> (14 px) or larger there.</p>
</Notes>

</DocSection>

<DocSection n={3} title="Text colors" description="Text outside components – a caption, a category line, secondary text – takes its color from a class.">

```html
<p class="medo-text-body-sm medo-text-secondary">Updated Nov 9, 2026</p>
<p class="text-body-sm text-text-secondary">Updated Nov 9, 2026</p>   <!-- Tailwind -->
```

<Notes>
  <p>One class per <Tok>text/*</Tok> token: <Tok>medo-text-primary</Tok>, <Tok>-secondary</Tok>, <Tok>-brand</Tok>, <Tok>-danger</Tok>, <Tok>-disabled</Tok>, <Tok>-inverse</Tok>, <Tok>-inverse-secondary</Tok>, <Tok>-on-brand</Tok>, <Tok>-on-brand-secondary</Tok>, <Tok>-on-action</Tok>, <Tok>-on-danger</Tok>, <Tok>-on-media</Tok>. They follow Light and Dark.</p>
  <p>Combine a text style and a color. Hover and pressed tones have no class: they belong to the components that react.</p>
  <p>Secondary text is for supporting information. What people must read to act stays <Tok>text/primary</Tok>.</p>
</Notes>

</DocSection>
