<DocSection n={2} title="Your job" meta="App">

<Notes title="The system cannot do these for you">
  <ul>
    <li>Page structure: one <Tok>h1</Tok>, headings in order, landmarks (<Tok>header</Tok>, <Tok>nav</Tok>, <Tok>main</Tok>), <Tok>SkipLink</Tok> first.</li>
    <li>The language of the page: <Tok>{'<html lang="de">'}</Tok> and the same locale in the I18nProvider.</li>
    <li>Real texts: labels for every field, alt text for images, link texts that name the target.</li>
    <li>Focus after changes: e.g. to the list heading after a page change, to the next item after a delete.</li>
    <li>Time limits: avoid them; if needed, allow more time (WCAG 2.2.1).</li>
  </ul>
</Notes>
