<DocSection n={3} title="Accessibility" meta="WCAG 1.1.1">

<Notes title="Icons are decorative – the name comes from the text">
  <ul>
    <li>Next to a label: <Tok>aria-hidden="true"</Tok>. The components do this for their icon slots.</li>
    <li>Icon only: an Icon Button with <Tok>aria-label</Tok> (“Close dialog”). The label is shown as a tooltip.</li>
    <li>Status: never the icon alone – a text or a hidden text says what it means (“Error:”, “Unread”).</li>
    <li>Contrast: an icon that carries meaning needs 3 : 1 against its background.</li>
  </ul>
</Notes>

</DocSection>

```tsx
import { Download } from 'lucide-react';
import { Button, IconButton } from '@med-o/ui';

<Button startIcon={<Download />}>Export</Button>
<IconButton icon={<Download />} aria-label="Export report" />
```

Without React: the same icons as SVG from `lucide-static`, sized with `width/height: var(--medo-size-icon-md)`.
