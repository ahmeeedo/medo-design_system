<DocSection n={1} title="Set the language" meta="I18nProvider" description="The language comes from React Aria. Without a provider it follows the browser.">

```tsx
import { I18nProvider } from 'react-aria-components';

<I18nProvider locale="de-DE">
  <App />
</I18nProvider>
```

Pin the language once at the root – also for an app in one language only (<Tok>locale="en-US"</Tok>). Otherwise a German browser shows German texts next to your English content. Regional variants use their language: <Tok>de-AT</Tok> and <Tok>de-CH</Tok> are German. Any other language falls back to English.

<DocSection n={4} title="Other languages" meta="MessagesProvider" description="Start from the English texts and replace them. TypeScript reports every missing text and wrong parameter.">

```tsx
import { MessagesProvider, enMessages, type Messages } from '@med-o/ui';

const fr: Messages = {
  ...enMessages,
  common: { ...enMessages.common, close: 'Fermer', cancel: 'Annuler' /* … */ },
  // …
};

<I18nProvider locale="fr-FR">
  <MessagesProvider messages={fr}>
    <App />
  </MessagesProvider>
</I18nProvider>
```

Texts with numbers are functions, so every language can use its own plural forms: <Tok>{'more: (n) => n === 1 ? \'1 weitere Ebene anzeigen\' : `${n} weitere Ebenen anzeigen`'}</Tok>.

</DocSection>

<DocSection n={5} title="Writing rules" meta="German">

<Notes title="How the German texts are written">
  <ul>
    <li>Buttons in the infinitive: „Schließen“, „Dateien auswählen“ – never „Schließe“ or „Klicken Sie hier“.</li>
    <li>Messages without addressing the user: „Bitte ein Datum ab dem 12.10.2026 wählen.“ „Ihre“ only where there is no other way.</li>
    <li>German quotation marks „…“, the Control key is „Strg“.</li>
  </ul>
</Notes>

See also Foundations / Content for the rules in both languages.
