Design System · Komponente · Code snippet

Code snippet

Code lesbar und kopierbar darstellen — inline im Text, als einzelne Zeile, als Block mit Zeilennummern oder als Terminal-Befehl. Dunkle Fläche mit dezenter Hervorhebung.

Inline

Führe npm install aus und importiere anschließend die Komponente mit import { Button } from 'medo' in deine Datei.

Einzeilig · mit Kopieren
npx medo init --template=app

Terminal · $-Prompt
$ medo build # erzeugt dist/
# Fertig in 2.4s
$ medo deploy
Kopieren legt den Text in die Zwischenablage; der Button bestätigt ~1,5 s mit „Kopiert!". Der Block klappt bei mehr als 8 Zeilen ein.

Einsatz
Do
  • Inline für einzelne Befehle/Bezeichner im Fließtext.
  • Block mit Kopieren für Mehrzeiler; Sprach-Label setzen.
  • Lange Blöcke einklappen und „Mehr anzeigen" anbieten.
Don't
  • Kein Fließtext im Code-Block — nur echter Code/Befehle.
  • Syntax-Farben dezent halten, nicht bunt überladen.
  • Kopieren-Button nicht ohne Bestätigung lassen.
